# PDF-urile pentru demo

Aici pun cei de la Product PDF-urile la care trimit scenariile din `../scenarios/*.json`. Sunt PDF-uri cu text real, nu scanări, ca extracția prin Bedrock să fie sigură.

| Fișier | Scenariu | Conținut |
|---|---|---|
| `oferta-aspersie.pdf` | irigații | ofertă de aspersie clasică pentru 40 ha, 85.000 EUR fără TVA |
| `fisa-tehnica-aspersie.pdf` | irigații | eficiența declarată, debit, presiune |
| `sistem-actual-tun.pdf` | irigații | descrierea sistemului actual (tun de irigat) |
| `oferta-tractoare.pdf` | utilaje | 4 tractoare Stage V, 110.000 EUR/buc. fără TVA |
| `fise-tehnice-tractoare.pdf` | utilaje | putere, normă de emisii, consum specific |
| `flota-actuala.pdf` | utilaje | tractoarele înlocuite (an de fabricație, putere) |
| `facturi-motorina-12-luni.pdf` | utilaje | consumul de motorină pe ultimele 12 luni |
| `oferta-fotovoltaice-300kwp.pdf` | energie | ofertă pentru 300 kWp pe acoperișul halelor, 210.000 EUR fără TVA |
| `facturi-energie-avicola-12-luni.pdf` | energie | 12 facturi lunare, 215.000 kWh pe an, 0,19 EUR/kWh fără TVA |
| `oferta-utilaje-bio.pdf` | ecologic | prășitoare cu cameră + grapă cu colți, 78.000 EUR fără TVA (DEMO-0006) |
| `contract-certificare-bio.pdf` | ecologic | contract cu organismul de certificare, 120 ha în conversie din 01.01.2027 |
| `plan-conversie-bio.pdf` | ecologic | calendarul conversiei pe culturi |
| `facturi-ingrasaminte-12-luni.pdf` | ecologic | 2 facturi de azotat de amoniu 34% N, 46.000 kg (15.640 kg N) |

Până apar PDF-urile, rularea demo pornește oricum și marchează documentele lipsă.
